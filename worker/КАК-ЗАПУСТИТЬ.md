# Как запустить сервер ИИ «Здаровенький»

Сервер — это маленькая программа в Cloudflare (бесплатно). Она хранит ваш ключ Claude API
и отвечает сайту: считает калории по фото, составляет меню, работает тренером.
Ключ **никогда** не попадает в телефон или на сайт — только на этот сервер.

Делается **один раз**, на компьютере. Нужно ~10 минут.

## Что понадобится
- Аккаунт Cloudflare (у вас есть).
- Ключ Claude API — строка, которая начинается с `sk-ant-` (у вас есть; найти можно на console.anthropic.com → API keys).
- Придумайте **семейный пароль** — например, 3–4 слова через дефис. Его будут вписывать все в семье.

> ✅ Уже сделано 21.11.2026. Адрес сервера: **https://zdorovenkiy-ai.egor-isaevusa96.workers.dev**
>
> На этом компьютере PowerShell не запускает `npx` — пишите **`npx.cmd`** вместо `npx`.
> Если вход не открывает браузер: `npx.cmd wrangler login --browser=false` и откройте ссылку в Edge.

## Шаги (в PowerShell)

1. Перейдите в папку сервера:
   ```powershell
   cd "$HOME\Desktop\ЗДАРОВЕНЬКИЙ\worker"
   ```
2. Установите нужные файлы (если папки `node_modules` ещё нет):
   ```powershell
   npm install
   ```
3. Войдите в Cloudflare — откроется браузер, нажмите **Allow** («Разрешить»):
   ```powershell
   npx wrangler login
   ```
4. Сохраните ключ Claude на сервере. Программа спросит значение — **вставьте ключ** и нажмите Enter.
   Если спросит, создать ли новый Worker, — ответьте `y`.
   ```powershell
   npx wrangler secret put ANTHROPIC_API_KEY
   ```
5. Сохраните семейный пароль (так же — вставьте и Enter):
   ```powershell
   npx wrangler secret put FAMILY_CODE
   ```
6. Запустите сервер в интернете:
   ```powershell
   npx wrangler deploy
   ```
   В конце появится адрес вида `https://zdorovenkiy-ai.ВАШЕ-ИМЯ.workers.dev` — **скопируйте его**.
7. Проверка: откройте этот адрес в браузере. Должно быть написано `{"app":"zdorovenkiy-ai","ok":true}`.
8. На телефоне в Здаровеньком: **Ещё → Настройки → ИИ-помощник** → вставьте адрес и семейный пароль →
   **Проверить** → **Сохранить**. Так же — у каждого в семье.

## Сколько стоит
Платите только за Claude API (с вашего счёта Anthropic), сервер Cloudflare бесплатный.
Примерно: фото — меньше 1 ¢ (модель Haiku), меню от ИИ — 20–40 ¢, ответ тренера — 1–3 ¢.
Совет: на console.anthropic.com в разделе **Limits** можно поставить лимит трат в месяц.

## Если что-то пошло не так
- **«Неверный семейный пароль»** — пароль на телефоне не совпадает с тем, что в шаге 5.
- **«Ключ Claude API не подходит»** — повторите шаг 4 с правильным ключом.
- **Пароль узнал кто-то чужой** — повторите шаг 5 с новым паролем и шаг 8 у всех в семье.
- Сменить модель ИИ можно в файле `wrangler.toml` (строка `MODEL`), потом снова `npx wrangler deploy`.

## Безопасность
- Не пишите ключ в файлы, в чаты и на сайт. Он живёт только в Cloudflare (шаг 4).
- Файл `.dev.vars` и папка `node_modules` не должны попадать на GitHub (это уже прописано в `.gitignore`).
