# Здаровенький — задание (по 30 ответам)

Программа для здорового образа жизни для семьи.

## Где и для кого
- Сайт, который ставится на главный экран iPhone как приложение (PWA). Работает и без интернета.
- Семья: 3–5 взрослых, **все с iPhone**. Каждый пользуется на **своём** телефоне, записи друг другу не видны.
- Живём в США. Единицы — **переключатель** (кг/г/мл ↔ lb/oz/fl oz).
- Язык — **русский + английский** (переключатель).
- Название под иконкой: **Здаровенький**.
- Дизайн выберем позже по картинкам из Codex. Пока простой аккуратный вид, цвета легко поменять.

## Что отслеживаем
1. **Вода** — кнопка «+1 стакан» (250 мл / 8 fl oz), цель на день (по умолчанию 8 стаканов).
2. **Еда** — полный подсчёт калорий:
   - записи завтрак/обед/ужин/перекус с калориями;
   - **фото еды → ИИ определяет блюдо и калории** (Claude API, модель Haiku — меньше 1 цента за фото);
   - **рецепты**: встроенная книга (больше русской домашней кухни + разные страны) + свои рецепты + ИИ;
   - **меню на неделю**: из книги рецептов или от ИИ (учитывает цель, калории, аллергии);
   - **список покупок** из меню: галочки, разбивка по отделам магазина, число порций выбирается.
   - У каждого в профиле: аллергии, нелюбимые продукты, диеты.
3. **Спорт** — запись (вид + минуты, примерный расчёт калорий) + готовые домашние тренировки с таймером.
4. **Шаги** — вписываем число руками (из «Здоровья» или часов).
5. **Сон + подробный дневник** — во сколько лёг/встал, качество сна, настроение, энергия, стресс, заметка.
6. **Вес + цель** — похудеть/держать/набрать, график, индекс массы тела.
7. **Привычки** — готовые + свои, галочка каждый день, серии дней 🔥.

## Мотивация
- Серии дней 🔥, очки и награды 🏅, совет дня, ИИ-тренер (раз в неделю разбор + можно задать вопрос).
- Тон каждый выбирает сам: добрый / с юмором / строгий сержант.
- **Анти-YouTube**: через «Команды» iPhone → Автоматизация «при открытии YouTube/TikTok/…» открывается сайт,
  считает заходы за день, **ИИ ругает** (тоном из настроек). На сайте — пошаговая инструкция настройки.

## Напоминания
- Настраиваемые push-уведомления на iPhone (сайт должен быть на главном экране, iOS 16.4+).
- Нужен маленький бесплатный сервер (Cloudflare Worker) — он же прячет ключ ИИ.

## Данные
- Хранятся в телефоне. Кнопка **«Резервная копия»** (файл, например в iCloud) + восстановление.
  Раз в неделю программа напоминает сделать копию.
